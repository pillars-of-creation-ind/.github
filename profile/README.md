## 🧭 What this org is

This is my personal lab. It is where I learn a topic by building or studying it in public, then
promote the best work to my main profile.

- **Original repos** here are my own learning projects and tutorials.
- **Forked repos** are study references: courses, open-source architectures and reference projects I
  read, run and annotate. They are not presented as my own work.

## 🔨 Current focus

- **AI systems:** agents, tool calling, RAG, evaluation, automation pipelines
- **Production backends:** layered architecture, PostgreSQL, migrations, CI
- **Frontend system design:** a long-running series on frontend architecture
- **Forward-deployed engineering:** turning ambiguous customer problems into working systems
